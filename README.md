## 📋 Descrizione

**Bomber & Friends** è un'applicazione web per la gestione di campionati di calcetto amatoriale. Permette di:

- 📊 Gestire classifiche per squadre e giocatori
- ⚽ Registrare partite con goal, assist, MVP e miglior portiere
- 👥 Gestire giocatori con foto e numeri di maglia
- 📈 Visualizzare statistiche complete
- 🔐 Autenticazione con Firebase
- 📱 Responsive per desktop e mobile
- 📤 Condivisione su WhatsApp, PDF, Immagine
